🔧 VOLT CLASH - Version avec déblocages

📋 Description

Cette version contient toutes les modifications de déblocage IA ajoutées pour résoudre les problèmes de blocage du jeu.

🚀 Fonctions de déblocage ajoutées

  • unblockBlueIA() - Déblocage spécifique IA bleue
  • emergencyUnblockGame() - Déblocage d'urgence complet
  • forceUnblock() - Déblocage radical
  • hardResetGame() - Réinitialisation complète

🎯 Actions pour revenir à l'original

Pour revenir à la version originale du jeu :

  1. Ouvre un terminal dans le dossier du projet
  2. Exécute : git checkout HEAD -- index.html
  3. Ou restaure depuis une sauvegarde si tu en as une

📂 Fichiers concernés

  • index.html - Fichier principal du jeu
  • index_avec_deblocages.html - Cette sauvegarde

⚠️ Note importante

Les fonctions de déblocage ont été ajoutées pour résoudre les problèmes de blocage IA. Si tu veux revenir à la version originale, utilise les commandes Git ci-dessus.
